# AETHER OS 1.2.0 · 发布说明

**版本**：1.2.0  
**构建日期**：2026-11-19  
**类型**：地图与全球黄页大版本  
**平台**：Android（Chrome + Termux）、iPhone / iPad（Safari + iSH）、桌面浏览器（预览）  
**性质**：PWA 概念系统 + 可选本地 Linux 桥接（非手机固件）

---

## 1. 版本摘要

AETHER OS 1.2.0 重做了地图，并新增全球黄页，把「地点、电话、路线」串成一条可用的真实链路：

- **地图全面重做**：全球地点搜索与相关度排序、GPS 定位与 IP 粗略定位回退、地点电话 / 营业时间 / 官网等详情、驾车 / 步行 / 骑行真实路线与中文分步指引；
- **新增黄页应用**：全球地点黄页、212 个国家与地区的紧急电话、7 类常用服务热线，并支持一键转入地图继续导航；
- **Leaflet 改为本地打包**：地图交互库随项目提供，不再依赖第三方 CDN；
- 应用总数达到 **17 个**：终端、电话、短信、微信、QQ、支付宝、浏览器、文件、办公、代码工作室、地图、黄页、备忘录、媒体、相册、相机与设置；
- 版本号、界面标识、桥接版本、Service Worker 缓存与双平台更新清单统一为 **1.2.0**。

> 这不是可刷入的 ROM，也不修改设备内核、引导链、基带或系统分区。电话、短信、微信、QQ、支付宝均只交接官方 App；系统消息接收与电话接听不在网页能力范围内。详见 [README](../README.md) 与 [完整说明书](MANUAL.md)。

## 2. 本版新增与变更

### 2.1 地图（重做）

- **全球搜索**：使用 Photon 地理编码，8 秒超时；单次最多请求 40 条，客户端去重后按「名称匹配度 + 地点类型 + 与当前位置距离」排序。
  - 精确名称、前缀匹配、景点 / 博物馆 / 观景点 / 塔等类型加权；
  - 住宅区、住宅楼、公交站、停车场、道路、地名等类型降权；
  - 同名小区、公交站不会再压过真正的目标地标；结果列表最多展示 20 条。
- **定位**：
  - 优先调用浏览器 Geolocation API，需要 HTTPS / localhost 与定位授权；
  - 授权被拒绝、超时或设备无 GPS 时，自动回退到 `ipinfo.io` 的 IP 定位；
  - 回退结果只到城市级，HUD 与状态文案明确显示 `IP APPROX · CITY LEVEL` / 「IP 粗略定位」，不冒充精确位置；
  - 定位状态同步到桌面系统卡片。
- **地点详情**：
  - 读取 OpenStreetMap / Overpass 标签，展示地址、电话、营业时间、官网、运营方 / 品牌；
  - 电话字段覆盖 `phone`、`contact:phone`、`contact:mobile`、`mobile`；
  - 根据国家显示紧急电话；OSM 未收录电话时明确提示，不编造号码；
  - 详情请求失败不影响标记与路线，并显示具体错误。
- **真实路线**：
  - 支持驾车 / 步行 / 骑行三种模式；
  - 驾车使用 OSRM 公共路由，步行与骑行使用 FOSSGIS 公共路由；
  - 返回真实道路几何、总距离、预计时间与中文分步指引；
  - 路线以发光折线与主线绘制，点击步骤可定位到对应路口；
  - 没有当前位置时自动请求 GPS 或 IP 粗略定位作为起点。
- **本地 Leaflet**：Leaflet 1.9.4 的脚本、样式、许可证与标记图片随项目提供，不再从 unpkg 或 jsDelivr 加载地图库。
- **边界**：不提供实时路况、公交 / 地铁换乘、离线搜索或离线路径规划；瓦片、搜索、详情与路线均需网络，离线只显示已缓存瓦片。

### 2.2 黄页（新增）

- **地点黄页**：与地图共用 Photon 全球搜索，直接查看地址、电话、营业时间与官网；可一键交给地图定位，或选择驾车 / 步行 / 骑行继续规划路线。
- **紧急电话**：内置 **212 个国家与地区**的报警、消防、急救、统一紧急号码与补充号码。
  - 支持按大洲筛选；
  - 支持按国家名称或代码搜索；
  - 根据 IP 粗略定位高亮当前国家或地区；
  - 点击号码通过 `tel:` 交给系统电话 App。
- **常用热线**：7 类共 40 余条，全部可点击呼出：
  1. 领事与海外求助；
  2. 支付与银行卡；
  3. 通信与运营商；
  4. 铁路 / 航空 / 出行；
  5. 快递与物流；
  6. 手机与电脑支持；
  7. 消费与政务。
- **数据边界**：黄页保存在本地 `js/hotlines.js`，离线可查看；号码可能随当地政策调整，以官方最新公布为准，网页不实时校验号码有效性；境外拨打需要正确加拨国际区号。

### 2.3 数据层与隐私

- 新增 `js/places.js`：Photon 搜索、Overpass 详情、OSRM / FOSSGIS 路由、IP 定位与地理计算。
- 新增 `js/hotlines.js`：212 个国家与地区紧急电话、7 类服务热线与号码清洗工具。
- 外部请求仅包括：Photon（搜索关键词）、Overpass（OSM 要素编号）、OSRM / FOSSGIS（起终点坐标）、ipinfo.io（IP 定位）、Esri（瓦片）与平台更新清单；均不经过本项目服务器。
- 无遥测、无账号、无广告、无第三方分析脚本；黄页数据完全本地。

### 2.4 其他

- 桌面应用总数更新为 **17 个**，新增 `yellow` 黄页应用与 `book`、`phone`、`route`、`globe` 等图标。
- Service Worker 预缓存加入 `places.js`、`hotlines.js` 与本地 Leaflet；缓存版本为 `aether-v1.2.0-b1`。
- `version.json`、桥接 `VERSION`、终端版本输出与全部文档统一为 **1.2.0** / 构建 2026.11.19。
- 更新全部文档、截图与介绍图片；发布包不包含 `bridge/.aether_token`。

## 3. 能力边界

1. **电话 / 短信**：网页只能请求系统 App 接管，不能读取通话记录、短信收件箱或送达回执，也不能接听 / 拒接电话。
2. **系统消息**：浏览器 / PWA 无法读取系统短信、微信、QQ、支付宝消息或通知；本项目不提供伪造的消息接收界面。
3. **Android 原生应用 / 游戏**：PWA 不能安装 APK、加载 DEX / 原生库或运行 Android 游戏；Android 上最多通过系统 Intent 打开已安装应用并离开浏览器，iOS 不允许此类跳转。
4. **微信 / QQ / 支付宝**：只唤起官方 App 或使用系统分享，不登录、不读取聊天、不代发消息、不查询支付结果。
5. **地图**：搜索、详情与路线依赖第三方公共服务，可能限流或不可用；IP 定位只到城市级；没有实时路况、公交 / 地铁换乘和离线路径规划。
6. **黄页**：号码为本地静态数据，可能随政策调整；`tel:` 只负责交接系统电话 App，网页无法确认是否拨出，也不验证号码是否仍有效。
7. **应用更新来源**：GitHub / GitCode 提供版本清单与发布页，但浏览器不能跨源替换已安装 PWA 的代码包；更新按钮只刷新当前安装地址。
8. **文件系统**：浏览器不能绕过系统权限访问整个手机；Android 依赖 Termux 桥接，iPhone 依赖 iSH 可见目录，桌面依赖用户授权目录。删除不可撤销。
9. **办公格式**：PDF 只支持页面与叠加文字层，不编辑原文字流；DOCX / PPTX 只编辑文字层；XLSX 不计算公式；`.doc` / `.ppt` 不解。
10. **相机**：不提供专业参数、RAW、后台录制；取景器画质取决于浏览器与设备；原生通道的实际调用方式由系统文件输入决定。
11. **不修改固件**：不接管基带、射频、运营商配置或系统分区。

## 4. 安装与升级

### 4.1 新安装

- **Android**：安装 Termux（F-Droid / GitHub）→ `bash bridge/setup-termux.sh` → `python3 bridge/server.py` → 浏览器打开 `http://127.0.0.1:8787`。
- **iPhone / iPad**：安装 iSH → `sh bridge/setup-ios-ish.sh` → `python3 bridge/server.py` → Safari 打开同一地址。
- **桌面预览**：`python3 bridge/server.py`，终端为静态模式。

### 4.2 从已有安装升级

1. 下载并解压 `aether-os-1.2.0.zip` 到新目录，保留自己的 `bridge/.aether_token`。
2. 停止旧桥接，从新目录执行 `python3 bridge/server.py`。
3. 刷新页面，或在设置 →「系统更新」中选择来源并刷新；缓存版本为 `aether-v1.2.0-b1`。若仍显示旧界面，再刷新一次或注销旧 Service Worker。
4. localStorage 中的设置、备忘录、代码与桥接配置会保留。
5. AETHER 空间（OPFS）、相册副本与目录授权按站点 origin 保留；建议升级前先下载重要文件。

完整步骤见 [完整说明书 · 第 3 章](MANUAL.md#3-获取校验与安装)。

## 5. 验证与测试

发布前在 Chromium 移动视口 525×553 + 本地桥接（静态模式与 Termux / iSH mock）完成：

- 启动、锁屏、桌面 **17 应用**与状态栏；
- 终端模拟三壳、桥接健康检查与静态降级；Termux / iSH 主机通道的界面切换与 host scope 分支；
- 电话 / 短信 / 微信 / QQ / 支付宝原生交接与复制回退；
- 文件：桥接文件 API 15 项测试；OPFS 与目录授权增删改查；
- 办公：PDF、DOCX、XLSX、PPTX、TXT 的打开与另存有效性；
- 代码：13 种语言说明面板、HTML / CSS 检查、`/api/studio` 探测 / 编译 / 运行 / DEBUG 路由；
- 相机：原生入口、取景器约束、自动 / 点按对焦与变焦代码路径；真实镜头画质需真机复测；
- **地图**：Esri 瓦片与本地 Leaflet；「东方明珠电视塔」在 40 条结果中经相关度排序后位列第一；GPS 被拒绝时回退到 IP 城市级并明确标注；地点详情返回地址、营业时间与官网；余姚 → 东方明珠电视塔驾车路线返回 176 km、约 2 小时 16 分、38 个中文步骤与真实道路折线；
- **黄页**：212 个国家与地区条目、大洲筛选、国家搜索、IP 国家高亮、7 类热线展示；地点详情与「驾车去」交接地图并自动规划路线；
- 备忘录、媒体、相册与浏览器；
- 省电三档、无 Battery API 回退、粒子暂停与渲染循环优化；
- manifest、Service Worker 激活、离线壳与新缓存清理；
- 全流程无控制台错误或警告。

真实 Termux 与 iSH 的命令执行依赖对应设备环境，发布包内的服务端分支与界面通道已按同一协议验证，但未在实体手机上复测；说明书测试表将这几项如实标记为「模拟界面 / 需真机复测」。

详细的逐项记录见 [完整说明书 · 第 13 章](MANUAL.md#13-测试与验收记录)。
